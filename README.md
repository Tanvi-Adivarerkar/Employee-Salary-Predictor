# Employee Salary Predictor

A Machine Learning project that predicts employee salaries based on different factors such as education, occupation, work class, and experience.

## Features

* Predict employee salary using Machine Learning
* Data preprocessing and feature engineering
* Salary prediction through a Streamlit web application
* User-friendly interface
* Real-time prediction

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* Matplotlib
* Seaborn

## Project Structure

* app.py → Streamlit web application
* salary_prediction.ipynb → Model training notebook
* employee_salary_dataset.csv → Dataset used for training
* salary_prediction_model.pkl → Trained Machine Learning model
* Employee_Salary_Predictor_Presentation.pptx → Project presentation

## How to Run

1. Install required libraries
2. Run app.py using Streamlit
3. Enter employee details
4. Click Predict
5. View the predicted salary

## Future Improvements

* Improve prediction accuracy
* Add more employee-related features
* Use advanced algorithms such as XGBoost and CatBoost
* Integration with HR management systems
